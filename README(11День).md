# RED ORB — мобильная версия

Мобильная адаптация платформера RED ORB для смартфонов и небольших экранов.

## Файлы
- `index.html` — мобильная структура и экранные кнопки.
- `style.css` — адаптивный интерфейс, safe-area и раскладки для портретной/альбомной ориентации.
- `script.js` — игровая логика, физика, уровни и сенсорное управление.

## Запуск
Открой `index.html` в мобильном браузере или загрузи файлы в GitHub Pages.

## Управление
- Кнопки `←` и `→` — катиться влево и вправо.
- Красная кнопка `↑ ПРЫЖОК` — прыгать.
- Также поддерживаются клавиши WASD, стрелки и пробел.

## Проверка
Проверь игру на ширине 320, 360, 390 и 430 px, в портретной и альбомной ориентации.
